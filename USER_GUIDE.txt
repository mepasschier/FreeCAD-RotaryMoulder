1. CONCEPTS
================================================================

THE MOULD DRUM
A rotary moulder drum is a cylinder with cookie-shaped cavities cut
into its outer surface. Dough is pressed against the drum, fills the
cavities, then the formed cookies are released onto a conveyor belt.

For cookies to release properly, every cavity wall needs DRAFT - the
floor of the cavity is narrower than the rim. This workbench handles
the draft automatically.

FLAT SKETCHES -> CURVED GEOMETRY VIA SKETCH_ON_SURFACE
You design the cookie outline as a flat 2D sketch on the XY plane.
Before passing it to this workbench, you project the sketch onto the
drum's cylindrical face using the CURVES WORKBENCH's
Sketch_On_Surface feature. The resulting Sketch_On_Surface object is
what you select as the "cookie outline" for the cavity.

The mapping convention:
  - Sketch X coordinate maps to angular position around the drum
  - Sketch Y coordinate maps to axial position along the drum
  - Full sketch width = one full wrap (2*pi) around the drum, so
    X range 0..(pi*diameter) corresponds to a full circumference

DETAIL AND DOCKER OUTLINES use FLAT sketches directly (no SoS
needed) - they are projected internally using the parent cavity's
SoS mapping. Use familiar Sketcher tools (rectangles, splines,
ShapeString text, points, etc.) for these.

OBJECT HIERARCHY
A typical project tree:

    Drum
    +- Cavity (or CavityPattern)
       +- Outline (a Sketch_On_Surface object)
       |  +- (source flat sketch on XY plane)
       +- CavityDetail        (letters/shapes)
       |  +- Outline (flat sketch on XY plane)
       +- CavityDockers       (perforation pins)
          +- Outline (flat sketch with points)

Each cavity can have multiple detail and docker children. The cavity
outline is an SoS object; detail and docker outlines are flat sketches.

DRAFT DIRECTION
All cavities use floor_narrower draft - the cavity opens wider at
the drum surface than at the floor, so dough pulls out cleanly.

For details (letters/shapes), the same logic applies:
  - Engrave (text recessed into floor): a small drafted pocket
    narrower at the bottom of the engraving
  - Emboss (text raised above floor): a small drafted bump,
    narrower at the top of the bump

In both modes the wider side is whichever is "outside" the cookie,
so the dough releases.

2. TUTORIAL: BUILD A COMPLETE MOULD
================================================================

This walkthrough builds a 6 x 3 pattern of rectangular cookies with
the letters "MSC" embossed and a few docker pins per cookie.

STEP 1 - CREATE THE DRUM
  1. Switch to the Rotary Moulder workbench
  2. Click the Create Drum button
  3. Accept defaults (D = 100 mm, L = 200 mm)
  4. A "Drum" object appears in the tree

STEP 2 - SKETCH THE COOKIE OUTLINE (FLAT)
The sketch goes on the XY plane. X = around the drum, Y = along it.

  1. Right-click in tree -> Create sketch -> XY_Plane
  2. Draw a rectangle (e.g. 12 x 25 mm)
  3. Close the sketch (Escape)

TIP: Keep sketch coords inside the cookie outline region of the
imaginary unwrapped drum. Y within drum length; X within
(pi * diameter), the circumference.

STEP 3 - PROJECT THE SKETCH ONTO THE DRUM (SKETCH_ON_SURFACE)
The cavity command expects an outline that has already been wrapped
around the drum's cylinder. Use the Curves Workbench to do this:

  1. Switch to the Curves Workbench
  2. Select the drum's outer cylindrical face,
     then Ctrl-click your flat sketch
  3. Click Curves -> Sketch on Surface
  4. A Sketch_On_Surface object (often labeled "SoS") appears in
     the tree, showing your sketch projected onto the drum

Switch back to the Rotary Moulder workbench.

STEP 4 - ADD THE CAVITY
  1. Select the drum AND the Sketch_On_Surface (Ctrl+click)
  2. Click Add Cavity From Sketch
  3. Accept defaults:
       Depth = 3.1 mm
       Draft angle = 16 degrees
       Fillet = 0.5 mm

The drum now has the cavity carved into it.

STEP 5 - ADD A DETAIL (TEXT)
  1. Make another FLAT sketch on XY plane (no SoS this time -
     details are projected internally)
  2. Sketcher -> ShapeString -> add "MSC" text
     TESTED FONT: verdanab.ttf (Verdana Bold) - reliable letter
     shapes. Other fonts may work but some have complex letter
     shapes that produce volume-estimation warnings (geometry
     still correct).

     IMPORTANT - TEXT MIRROR FOR COOKIE READABILITY:
     Because the cookie is formed by the drum's NEGATIVE volume,
     text needs to be pre-mirrored on the drum so it reads right
     on the formed cookie. To do this:
       - Attach the ShapeString to the SoS's Mapped_Sketch
       - Set Map Mode = InertialCS
       - Set Map Reversed = Yes
     The text will look BACKWARDS in the FreeCAD viewport - that
     is correct. It will read normally on the produced cookie.

  3. Position it inside the cookie outline area
  4. Close the sketch
  5. Select cavity AND detail sketch
  6. Click Add Detail to Cavity
  7. Choose mode (emboss/engrave), depth, draft angle

STEP 6 - ADD DOCKER PINS
Docker pins are perforations that pierce through cookies.

  1. Make another FLAT sketch on XY plane
  2. Sketcher -> Create point -> place a few points within cookie area
  3. Close the sketch
  4. Select cavity AND points sketch
  5. Click Add Docker Pins to Cavity
  6. Choose tip diameter (0.2 mm default), draft (16 deg)

STEP 7 - PATTERN AROUND THE DRUM
  1. Select drum AND cavity
  2. Click Pattern Cavities Around Drum
  3. Set count around, count axial, spacing, offset, layout

Every cavity instance inherits source details and docker pins.

STEP 8 - EXPORT
File -> Export As... to save as STEP/STL/etc.

3. COMMAND REFERENCE
================================================================

CREATE DRUM
  Creates a cylindrical drum at origin, axis along Y.
    Diameter      default 100 mm
    Length        default 200 mm

ADD CAVITY FROM SKETCH
  Cuts a drafted cavity into the drum. Requires drum + a
  Sketch_On_Surface object (cookie outline projected via Curves
  Workbench) selected.
    Depth         default 3.1 mm
    Draft angle   default 16 deg
    Fillet radius default 0.5 mm

  The workbench also accepts a plain flat sketch as fallback (via
  an older code path), but Sketch_On_Surface is strongly recommended
  for accurate projection onto the drum.

ADD DETAIL TO CAVITY
  Adds engraved/embossed text or shapes to the cavity floor.
  Requires cavity (or pattern) + FLAT sketch on XY plane.
  Sketch is projected internally using parent cavity's SoS mapping.
    Mode          default engrave (or emboss)
    Depth         default 0.5 mm
    Draft angle   default 16 deg

  A single detail can contain multiple shapes - e.g. one sketch
  with the text "MSC" produces three letter chunks treated together.

  SHAPESTRING FONT: workbench tested with verdanab.ttf
  (Verdana Bold). Other fonts may work but some have complex letter
  shapes that produce volume-estimation warnings in the report view
  (geometry is still correct).

ADD DOCKER PINS TO CAVITY
  Adds perforation pins to the cavity floor. Pin tips reach the
  drum surface (cookie pierced all the way through).
  Requires cavity + FLAT sketch containing POINTS.
    Tip diameter  default 0.2 mm
    Draft angle   default 16 deg

PATTERN CAVITIES AROUND DRUM
  Replicates a cavity (with details and dockers) around the drum.
  Requires either:
    - Drum + Cavity (uses cavity's existing settings); or
    - Drum + Sketch_On_Surface (also asks for cavity parameters)
  Parameters:
    Count around   default 6
    Count axial    default 3
    Spacing        default 50 mm
    Axial offset   default 25 mm
    Layout         default linear (or alternating)

IMPORT COOKIE OUTLINE (SVG/DXF)
  Imports an SVG or DXF as a flat sketch.

TOGGLE DEBUG INTERMEDIATES
  Saves intermediate construction shapes to an RM_Debug group.
  State persists across FreeCAD sessions.
  Button label may not refresh until you switch workbenches.

4. OBJECT REFERENCE
================================================================

DRUM PROPERTIES
  Diameter   Length  default 100 mm
  Length     Length  default 200 mm

DRAFTEDCAVITY PROPERTIES
  Drum            Link      required (parent drum)
  Outline         Link      required - Sketch_On_Surface projecting
                            a flat sketch onto the drum
  Depth           Length    default 3.1 mm
  DraftAngle      Angle     default 16 deg
  DraftDirection  Enum      floor_narrower (only option)
  FilletRadius    Length    default 0.5 mm (0 disables)
  Details         LinkList  []
  Dockers         LinkList  []

CAVITYDETAIL PROPERTIES
  Cavity          Link      required (parent cavity or pattern)
  Outline         Link      required - FLAT sketch on XY plane
  Depth           Length    default 0.5 mm
  DraftAngle      Angle     default 16 deg
  DraftDirection  Enum      floor_narrower
  Mode            Enum      engrave or emboss

CAVITYDOCKERS PROPERTIES
  Cavity          Link      required
  Outline         Link      required - FLAT sketch on XY plane with
                            point vertices
  TipDiameter     Length    default 0.2 mm
  DraftAngle      Angle     default 16 deg

CAVITYPATTERN PROPERTIES
  Drum            Link      required
  SourceCavity    Link      optional (inherits details, dockers, etc.)
  Outline         Link      used when SourceCavity is None
  Depth           Length    default 3.1 mm   (when no SourceCavity)
  DraftAngle      Angle     default 16 deg   (when no SourceCavity)
  FilletRadius    Length    default 0.5 mm   (when no SourceCavity)
  CountAround     Integer   default 6
  CountAxial      Integer   default 3
  Spacing         Length    default 50 mm
  AxialOffset     Length    default 25 mm
  Layout          Enum      linear or alternating
  Details         LinkList  []
  Dockers         LinkList  []

5. PATTERNS
================================================================

TWO WAYS TO DEFINE A PATTERN
  - From a Cavity (recommended): make one cavity with details and
    dockers, then pattern it. Pattern inherits everything.
  - From a Sketch_On_Surface: skip the standalone cavity. Useful
    for simple patterns without details.

HOW THE PATTERN IS BUILT
The workbench builds the cavity-with-details once at the origin
(the "master"), then copies and rotates that master to each pattern
position and does a SINGLE boolean cut. Much faster than building
each cavity independently.

LINEAR VS ALTERNATING LAYOUT
  - Linear: cavities aligned in a perfect grid
  - Alternating: every other row offset by half the angular step
    (brick-like). Good for packing more cookies on the drum.

ADDING DETAILS TO THE PATTERN
You can attach extra details/dockers directly to the CavityPattern
(in addition to those inherited from the SourceCavity). These apply
to every cavity instance.

6. DOCKER PINS
================================================================

ANATOMY OF A PIN
Each pin is a truncated cone with a hemispherical (dome) tip:

       (dome)
       /---\
      /     \    <- tip diameter (e.g. 0.2 mm)
      |     |
      |     |
     /       \   <- truncated cone with draft
    /         \
   /___________\ <- base diameter = tip + 2*height*tan(draft)
  cavity floor

The pin's tip sits just below the drum's outer surface (0.05 mm
clearance for boolean reliability).

HOW POSITIONS ARE SPECIFIED
The outline sketch should contain POINTS (Sketcher -> Create Point).
Each vertex in the sketch becomes one pin. Sketch X = around drum,
Sketch Y = along drum.

DEFAULT PARAMETERS
The default 0.2 mm tip is sized for cracker-style perforations.
For larger biscuit perforations try 0.5 - 1 mm. Base diameter
scales automatically with depth and draft angle.

7. DEBUG MODE
================================================================

When geometry construction fails (or to understand what's happening),
enable debug mode by clicking the Toggle Debug Intermediates button.
Intermediate shapes are saved into an RM_Debug group:

  RM_cav_rim_wire       Cookie outline on drum surface
  RM_cav_floor_wire     Outline at cavity floor (scaled inward)
  RM_cav_side_shell     Loft surface between rim and floor
  RM_cav_top_cap        Top closing face (on drum surface)
  RM_cav_bot_cap        Bottom closing face (on cavity floor)
  RM_cav_solid          Final cavity-chunk solid
  RM_det_fN_outer_*     Detail face N: chunks/wires/caps/solid

Debug state persists across FreeCAD sessions.

8. TROUBLESHOOTING
================================================================

TEXT IN DETAILS COMES OUT BACKWARD ON THE FORMED COOKIE
  When the cookie is formed by the drum's negative space, anything
  on the drum is mirrored relative to the cookie. To compensate:
    1. Attach the ShapeString to the SoS object's Mapped_Sketch
    2. Set Map Mode = InertialCS
    3. Set Map Reversed = Yes
  This pre-mirrors the text on the drum so the formed cookie reads
  the right way around. The text will LOOK BACKWARDS in the FreeCAD
  viewport - that is correct. The same principle applies to docker
  pin positions if they should match a specific orientation.

THE CAVITY IS HUGE / MISSHAPEN
  - MISSING SKETCH_ON_SURFACE: the cavity outline should be a
    Sketch_On_Surface object, not the flat sketch itself. The SoS
    object is what tells the workbench where on the drum the outline
    belongs. If you select the flat sketch directly, the workbench
    falls back to a less-accurate projection that may misposition
    the cavity.
  - Source sketch must be on the XY plane
  - Sketch coords must be within drum's unwrapped region:
    X = 0 to circumference, Y = 0 to drum length
  - Open wires: the sketch must have a closed outline.
    Use Sketcher's validate-sketch tool.

LETTER CHUNK VOLUME WILDLY OFF
  Happens for complex letters with the generalFuse cap method.
  The workbench detects and falls back automatically. Shape will
  still be correct visually even when volume estimate is off.
  Tested font verdanab.ttf works reliably.

PATTERN PRODUCES BROKEN CAVITIES / MISSING LETTERS
  Known issue with Part.Compound(...).cut() and successive fuse()
  calls degrading topology. The workbench now batches all chunks
  through multiFuse first. If you see this regression, please report.

DOCKER PINS FAIL WITH "EMPTY RESULT"
  Pin tips sit 0.05 mm below drum surface. If cavity depth is very
  shallow (close to tip radius), pins may not have enough room.
  Try increasing cavity depth or decreasing tip diameter.

"NULL SHAPE" ERROR IN PATTERN
  Usually a master construction step failed silently. Enable debug
  mode and check the report view. Common causes:
    - outline with self-intersecting edges
    - detail sketch positioned outside the cavity outline
    - pattern that wraps around the drum
      (count_around * angular_step >= 360 deg with small overlap)

TOGGLE DEBUG BUTTON LABEL DOESN'T UPDATE
  Menu/toolbar text shows the state at workbench-init time.
  Switching to another workbench and back will refresh it.
  The toggle state IS persistent and IS applied - label is cosmetic.

"STILL TOUCHED AFTER RECOMPUTE" WARNING
  Harmless - a FreeCAD internal warning when objects in the parent
  chain are recomputed in non-strict order. Geometry is fine.

PATTERN DOESN'T APPEAR / SHOWS EMPTY
  Make sure the source cavity itself recomputed without errors.
  Check that CountAround * CountAxial > 0 and spacing values are
  sensible relative to drum length.
